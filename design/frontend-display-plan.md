# AI POSITION · 前端展示方案 v1

设计日期：2026-09-15。基于本地首轮数据：80 个岗位／方向条目、117 份资料、83 个技能主题。本文是展示与交互方案，尚未实现页面。

## 1. 设计定位

**AI 职业探索站：以职业展馆的方式进入，以共享知识库的方式阅读。**

主要访客：探索职业的学生与转型者、寻找专项资料的工程师、补充内容的贡献者。

核心路径：浏览岗位 → 理解职责 → 查看关联技能 → 打开学习资料。也支持直接搜索资料，或从技能反查岗位。

视觉方向：深色工业展馆。石墨黑、暖白文字、荧光黄绿强调、细网格、编号与清楚的分区。用关联高亮、层级展开和排版制造科技感。

## 2. 信息架构

| 页面 | 建议路径 | 用户目标 |
|---|---|---|
| 探索岗位（首页） | / | 浏览岗位板块，搜索并展开岗位 |
| 岗位详情 | /roles/:id | 看懂职责、技能、细分方向与资料 |
| 学习资料库 | /resources | 跨岗位查找课程、教程、项目与文档 |
| 技能专题 | /skills/:id | 看一种技能连接哪些岗位和资料 |
| 资料详情 | /resources/:id | 阅读推荐理由、使用条件、关联岗位，再访问原站 |
| 关于与贡献说明 | /about | 理解收录规则、来源口径与贡献方式 |

顶部导航：AI POSITION / 岗位探索 / 学习资料 / 技能图谱 / 推荐资料。

“技能图谱”进入技能探索视图。页面首版不必增加独立的后台、个人中心或学习进度。

## 3. 首页：展馆式岗位探索

### 首屏结构

桌面以 1440px 宽度为设计基准，内容最大宽度约 1320px。顶部导航 72px，左右边距至少 32px。

首屏标题区约 240–300px，左侧大标题：

> 探索 AI 时代的工作。
>
> 从岗位出发，找到技能与学习资料。

右侧是一幅静态为主的局部知识网络：FDE、AI 应用工程师、Agent、RAG、评测。悬停技能时突出相关节点；不持续旋转。

标题区底部显示“80 个岗位与方向 · 117 份学习资料 · 83 个技能主题”，并放置大搜索框：“搜索岗位、技能或资料，如 FDE、RAG、模型评测”。这些数字只表达收录规模。

首屏下半部应露出第一组岗位，避免标题区占满整屏。

### 浏览区域

左栏 216px：10 个板块及各自条目数。支持点击定位／筛选；固定时避开顶栏。

右侧：工具条 + 岗位卡片。工具条包含当前板块、结果数、条目类型筛选、卡片／图谱切换。

默认按板块浏览，主岗位卡片下显示细分方向入口。可切换“全部条目”查看完整 80 条；统计区分“主条目数”和“含细分方向总数”，不把隐藏条目计作当前可见结果。

卡片建议三列，每张约 300–340px 宽。普通卡片统一高度，板块标题、编号与留白提供节奏。可在首页单独放一张宽卡突出 FDE，但不影响结果区的排序。

### 岗位卡片字段

1. 板块编号 / 板块名。
2. 中文岗位名称，英文名称或简称作为第二行。
3. 40–60 字的一句话职责，超过两行截断。
4. 最多 3 个技能标签，剩余显示 +N。
5. 资料数量与细分方向数量。
6. 口径徽标：岗位实例 / 细分方向 / 国内职业 / 国内工种等。

“企业实践称谓”“技能方向”等徽标解释收录口径；不设计为权威或热门认证。实际卡片文案与计数从数据计算。

点击卡片主体展开详情；技能标签和细分方向是独立按钮，不嵌套在链接内。

## 4. 岗位详情：保留探索上下文

桌面端用约 600px 宽的右侧详情面板快速展开。背景列表位置保持不变，提供“打开完整页面”和复制链接。按 Esc、点击关闭按钮或浏览器后退可返回原结果与滚动位置。

完整详情页采用“主内容 + 右侧小目录”，内容顺序：

1. **名称与定位**：中英文、口径、所属板块、简述。
2. **关联技能**：点击进入技能专题。
3. **对应学习资料**：核心内容，在桌面详情首屏就露出开头；可按中文、入门、教程、项目筛选。
4. **细分与相邻岗位**：细分关系单独显示；相邻岗位根据共享技能计算并标注“共同技能”，不称为晋升路径。
5. **来源与维护记录**：收录依据、核验状态、采集时间、纠错入口。

正文采用连续滚动加锚点，避免把学习资料藏在多层页签后。暂无内容的“典型任务”“实践案例”不生成虚构文本；以后补齐再增加对应区块。

## 5. 资料库：高密度但易扫读

默认使用横向资料行，每行展示：

```
教程  Hello Agents                                  ↗ 访问资料
      Datawhale · 中文 · 基础
      系统学习智能体原理与实现。
      Agent / AI 应用开发             关联岗位 4 · 已打开入口
```

上述数量只作布局示意，实现时按关联数据计算。

搜索框下提供语言、资料类型、难度、关联技能和核验状态筛选。默认保持编辑顺序，允许按名称排序；没有可靠发布日期时不提供“最新发布”。

点击标题进入资料详情；单独的“访问资料”打开原站新标签页。资料详情包括推荐理由、前置知识、版本说明、关联岗位、来源与核验说明。

较长链接不直接显示在资料行，使用来源域名。核验状态以明确文字为主：

- 已打开入口：只说明入口可读取，不显示“质量认证”。
- 仅搜索确认：琥珀色小标签，可查看限制原因。
- 访问受限：弱化显示，提供说明与问题反馈；不默认隐藏以免用户误以为资料不存在。

没有个人收藏、打卡、完成比例或学习进度。

## 6. 技能专题与图谱

技能专题以“RAG”为例：主题名称 → 通俗说明（待编辑补充）→ 相关岗位 → 推荐资料 → 相关技能。

图谱默认展示 10 个板块与其规模，选择板块再展开岗位；选中岗位时显示其技能。资料以侧栏列表呈现，避免一次绘制全部关联线。

图形语义：岗位为矩形，技能为圆点；板块为带标签的区域。颜色和形状共同区分节点。

直观交互：点选“评测”，高亮涉及评测的岗位；旁边列表同步显示结果。筛选是持久选择，悬停只是短暂预览。

连线表示“所属”或“关联”，不表达职业先后、重要性或晋升关系。图例始终可访问。提供复位、缩放与列表切换，支持键盘通过同步列表完成同样任务。

## 7. 视觉系统

| 用途 | 设计值 |
|---|---|
| 页面背景 | #0C0F0D，带很淡的网格 |
| 内容表面 | #151A17 |
| 悬停表面 | #1E2721 |
| 主文字 | #F1F4EC |
| 次文字 | #A5B1A7 |
| 主强调色 | #D6FF62，主要按钮与选中状态 |
| 辅助强调色 | #70D8CE，用于部分技能关联 |
| 提示色 | #F0BF70，用于核验限制 |
| 边框 | #303C33；输入框和焦点边界需有更强对比 |

中文优先考虑思源黑体／Noto Sans SC，展示标题可用较重字重；英文大标题考虑 Archivo，编号与短标签考虑 IBM Plex Mono。实际加载前确认字体许可和字体子集体积。中文正文 16px，行高约 1.75；元信息不小于 12px。

圆角：面板 12px、卡片 8px、按钮 6px。强调利落边缘、细分隔线和明确层级。

动效：卡片悬停 160ms、详情展开 240ms；页面进入只对首屏做一次轻微错位淡入。保持标准光标，不使用循环粒子、打字机正文或滚动劫持。支持减少动态效果偏好。

所有颜色组合在实现阶段进行文字对比度检查，以上为初始设计值。

## 8. 搜索、响应式与基础状态

- 全局搜索覆盖中文名、英文名、别名、技能和资料标题；结果按岗位、技能、资料分组。
- 点击搜索结果直接进入对应内容；显示命中的别名，帮助理解 FDE 等缩写。
- 搜索和筛选保存在 URL 参数中，可复制分享；浏览器返回恢复筛选。
- 手机小于 768px：单列卡片、板块横向导航、底部筛选面板；岗位进入全屏详情。
- 平板 768–1199px：双列卡片，分类可收起。
- 桌面 1200px 以上：左分类栏 + 三列岗位，右侧详情面板按需展开。
- 无搜索结果：显示搜索条件与清除按钮，允许推荐缺失岗位；不伪造推荐结果。
- 加载失败：简短错误说明与重试；筛选和已输入的资料内容保留。
- 信息缺失：省略对应区块或显示“待补充”，不虚构职责、贡献者和更新时间。
- 键盘：可见焦点、面板焦点管理、关闭后返回触发卡片；图谱有列表替代。

## 9. 共享贡献入口

每个岗位可“推荐相关资料”，每条资料可“反馈问题”。全局推荐入口支持粘贴链接，并填写推荐理由、关联岗位／技能。

提交前按标准化链接查重；遇到已有资料，建议补充说明或关联岗位。提交后进入待审核状态，只有真实审核通过才进入公共目录。

现有数据没有贡献者、审核历史与提交后端，设计稿只预留结构。实施阶段须连接真实提交渠道后再启用按钮与成功反馈，不展示虚构贡献活动。

## 10. 页面制作顺序与验收

第一组：岗位首页、岗位详情、资料库、资料详情、技能专题。先把搜索、筛选和跨页面关联做完整。

第二组：局部图谱交互、共享贡献表单和审核流程。视觉稿中可展示图谱方向，实际功能按实现状态明确标识。

验收重点：

1. 从首页两次点击内到达岗位关联的资料原站。
2. FDE、中文岗位名和别名都能检索。
3. 同一资料跨岗位复用，数量与本地关联数据一致。
4. 口径和核验状态可见，不把方向当成独立新职业。
5. 移动端无横向溢出；返回浏览位置正确。
6. 全部主要任务可通过键盘和列表完成，动画可减弱。
7. 不出现虚构热度、薪资、评分、学习时长与个人进度。

## 待视觉评审的主要选择

本方案默认采用“石墨黑 + 荧光黄绿”的工业展馆方向，默认首页为岗位卡片，图谱作为探索视图。下一步最有价值的产物是首页与 FDE 详情两张高保真视觉稿，用真实数据检查视觉密度和可读性。
