**采集日期：2026-09-15**

- 两个未获得可靠内容的候选已排除；LLM Universe 的在线版与仓库版已合并。
- 页面可读不等于课程永久免费；视频播放、完整章节、证书、商业服务、API 和算力费用未逐项核实。

## 数据结构

| 文件 | 用途 |
|---|---|
| knowledge-base.json | 主数据，包含 metadata / roles / resources / skills / sources |
| roles.json | 岗位名称、检索别名、口径、父岗位、技能、资料 ID、来源 ID |
| resources.json | 资料标题、主链接、备用链接、语言、类型、难度、前置知识、核验说明 |
| skills.json | 稳定技能 ID 与中文名称 |
| sources.json | 岗位来源、证据类型、原链接、解析链接和核验说明 |
| relations.json | 有类型的图谱边；推荐顺序是编辑建议，不是学习进度 |

### 核心字段约定

- `kind`：展示时必须保留，用于区分岗位、细分方向和工种。
- `parent_id`：明确 FDE 行业变体、Agent 细分方向等层级，避免重复计数。
- `verification_status`：核验状态，不是学习状态。
- `checked_at` / `collected_at`：本轮访问或整理日期，不是内容发布日期。
- `publication_date`：未逐条取得可靠发布日期，统一为 null；已知届次另记 `edition_note`。
- `summary_basis` / `resource_mapping_basis`：明确编辑归纳与来源事实的边界。
- `source_ids`：技能方向可为空；正式职位实例必须有依据。

## 后续补充重点

1. 中国公司岗位样本：部分招聘站为动态页面，本轮海外技术招聘证据较丰富，国内市场不能据此推断。
2. 非技术岗位：内容运营、商业分析、采购与 AI 治理等方向仍需更多独立岗位证据和专业课程。
3. 行业资料：医疗、法律和教育条目目前主要关联通用 AI 技术资料，不构成完整行业培养方案。
4. 系统与机器人方向：集群网络、设备控制等需补充岗位特有的基础课程。
5. 深度质量审阅：课程样章、项目可运行性、资料时效、中文翻译质量和许可需后续逐项审核。
6. 论文阅读：本轮偏重可学习和可实践资料，研究前沿论文尚未系统收集。

## 更新方式

编辑 knowledge-base.json 后运行 `python3 research/ai-careers/build_catalog.py`，即可重新生成目录、拆分 JSON、关联数据、校验报告和 ZIP。

build_catalog.py 只生成本地研究资料，不会开发或发布网站。
